# JAPAN QUAKE LAB — 地震・津波シミュレーター (Web Edition)

Python/Tkinterを使わず、HTML・CSS・JavaScriptのみで動く静的Webアプリです。ビルド手順やnpmパッケージは不要です。GitHub Pagesにも配置できます。

## ファイル構成

```text
japan-quake-web/
├── index.html
├── styles.css
├── data.js
├── app.js
├── README.md
├── LICENSE
└── data/
    └── official_scenario_template.csv
```

## 起動

- **最も簡単:** `index.html` をブラウザーで開きます。地理データは `data.js` に含まれ、CDNやバックエンドは必要ありません。
- **GitHub Pages:** リポジトリのルートにファイルを置き、Settings → Pages で `Deploy from a branch`、`main` / `/(root)` を選択します。
- **VS Code:** Live Server拡張機能などのローカル静的サーバーを使って開くこともできます。

## モード1 — 公的想定／実測データ

公的な計算結果と実測値の混同を避けるため、CSVに入力された値を表示します。CSVの全行を読み込み、データ区分・シナリオ・ケースで絞り込めます。公的PDFのテーブルはレイアウトが複雑なため、意図しない列のずれや抽出漏れを避ける目的で、このWeb版ではPDFを自動パースしません。公式資料を元に整理したCSVを取り込み、元資料と突き合わせてください。

### CSVの形式

`data/official_scenario_template.csv` がヘッダーのみのテンプレートです。**実測や公的な値は同梱していません。**

| 列 | 意味 |
|---|---|
| `source_type` | `公的想定` または `実測` |
| `scenario` | 想定名・地震名 |
| `case` | ケース名 |
| `source_url` | 元資料のURL |
| `prefecture` | 都道府県 |
| `municipality` | 市区町村名・観測地点名 |
| `latitude`, `longitude` | 地点の緯度・経度（わからなければ空欄可） |
| `intensity` | 震度（例: `5強`）。値が未掲載の場合は空欄 |
| `tsunami_height_m` | 津波高（m）。資料にない場合は空欄 |
| `arrival_min` | 表示対象にする到達時間（分）。しきい値が異なる値は別列に残してもよい |
| `arrival_1m_min` 〜 `arrival_20m_min` | 津波高1m / 3m / 5m / 10m / 20m到達時間（分） |
| `observed_at` | 実測値の観測日時 |

ケースや地点が複数ある場合は、**1地点・1ケースにつき1行**で記録してください。数値がないものを`0`にせず、空欄にします。都道府県庁所在地の座標へ代替配置した地点は、地図上の位置が代表位置であることに注意してください。表はCSVに入っているすべての行を保持します。

## モード2 — 条件を変えて試す

震源候補、緯度・経度、マグニチュード Mw、深さ、仮定する初期海面変位、変位の広がり、外洋の水深、計算対象時間を変更できます。震源は複数登録できます。結果は47都道府県庁所在地と35沿岸代表地点について、地図・一覧・CSVで表示します。

### モデル上の重要な限界

このモードは防災用の物理シミュレーターではなく、**感度実験のための簡易モデル**です。

- 地震動は簡略化した距離減衰式に基づくPGA参考推定で、そこから粗く震度クラスに換算します。気象庁の計測震度算出方法ではなく、地盤増幅、断層の有限サイズや指向性、地域の地質を十分に考慮していません。
- 津波高は入力された初期海面変位・広がりから作る経験的な距離減衰値です。海底地形を解く浅水方程式や断層すべりの逆算は実装していません。到達時間は仮定水深で求めた波速と直線距離による目安で、実際の津波到達時間ではありません。
- マグニチュードから海底変位を自動的に導出していません。津波値は初期海面変位の入力次第です。
- 複数震源は、地点別に強い推定値を選びます。波の物理的な重ね合わせは行いません。
- 47庁所在地と35沿岸地点は日本全国の全市町村・全海岸を網羅しているわけではありません。

## 安全に関する注意

このアプリは教育・学習・UI試作向けです。地震発生時の避難、津波警報の判断、被害推定、建物の安全性判定には利用しないでください。災害時は気象庁・自治体・消防等の公式情報に従ってください。

## 開発情報

フレームワークなし、HTML/CSS/vanilla JSのみ。計算結果のCSV書き出しとブラウザー開発者コンソールへの `console.table` 出力に対応します。実測の自動取得、公式PDFの自動表抽出、地理院タイルの利用は実装していません。


## 更新：海外の震源候補とMw入力範囲
- 千島列島、カムチャツカ半島、サハリン、アリューシャン列島、台湾近海などを候補に追加しました。
- 地図の表示範囲を北西太平洋へ拡張しました。
- 自由設定のMw入力には上限を設けていません（下限は4.0）。非常に大きな数値でも計算途中のオーバーフローを避ける処理をしていますが、これは科学的な妥当性を意味しません。極端なMwへの外挿は、実在する地震としての意味も推定式の精度も保証されません。
- **重要：震度推定式は依然としてスクリーニング用の簡易式で、気象庁の計測震度やUSGS ShakeMapの代替ではありません。** 震度を本当に精度よく得るには、実地震なら観測データ、仮想地震なら地域に適合した地震動予測式（GMPE）、断層形状、地盤条件等が必要です。
- 公式資料：気象庁「計測震度の算出方法」 https://www.jma.go.jp/jma/kishou/know/jishin/kyoshin/kaisetsu/calc_sindo.html 、USGS ShakeMap https://earthquake.usgs.gov/data/shakemap/


## マグニチュード入力の上限
Mw入力欄には上限を設定していません。数値演算は大きな有限値でオーバーフローしにくいようにしています。一方、自由設定モデルはあくまで簡易的な教育用スクリーニング式で、巨大な値のときに現実の揺れを予測する保証はありません。震度階級は気象庁の尺度上、震度7が最大表示です。Mwを際限なく増やしても、表示が7を超えることはありません。


## 改訂：震度スクリーニング式と水深の自動取得

- 地点ごとの簡易指標を `I* = a Mw − b log10(Rhyp) − c` として計算します。`Rhyp` は震源から地点までの水平距離と震源深さから求める震源距離です。係数は `a=1.35, b=2.2, c=1.0` の説明用仮置きであり、国内地震記録に回帰して校正したGMPEではありません。したがって「震度の精度が向上した」と保証するものではなく、式の形を明示して振る舞いを確認するスクリーニングです。正式な計測震度は気象庁の加速度波形フィルター処理・継続時間評価とは異なります。
- 最大震度カードは、震度一覧に含まれる全地点（都道府県庁所在地＋沿岸代表地点）から最大値を選ぶよう統一し、一覧より最大値が小さくなる不整合を修正しました。
- 震源座標の変更時に OpenTopoData の `gebco2020` endpoint を呼び、GEBCO 2020全球標高・水深の1点サンプルを取得します。標高値が負ならその絶対値を水深の参考値として入力欄に反映します。陸上座標、通信失敗、CORS、API制限の場合は状態を表示し、手動入力値を保持します。
- 水深取得の出典：GEBCO 2020（OpenTopoData経由） https://www.opentopodata.org/ 、GEBCO https://www.gebco.net/data_and_products/gridded_bathymetry_data/ 。取得値は震源位置の1点標高であり、沿岸全域の水深格子を取得したり、津波の浅水方程式を解いたりするものではありません。水深が取得できない場合、現在の手動値が使われます。
- 震度階級は震度0〜7の表示区分に収めます。マグニチュード入力上限なしは維持しますが、式をその範囲外へ外挿しても科学的な妥当性は保証されません。
